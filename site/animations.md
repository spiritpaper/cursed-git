# Animations

Nine short animations of the game and of git itself. They play right here in the browser:
click through them, or add `?video` to the address for a clean full-screen stage with no
buttons (that's what gets recorded for videos).

| Animation | What it shows | Try |
|---|---|---|
| [How git works](git-explained.html) | Snapshots, branches, merge, rebase, pull, conflicts, and the commit sacrifice | [`?scene=7`](git-explained.html?scene=7) |
| [Inside cg](git-internals.html) | What each command really writes into `.git`, in 13 scenes | [`?scene=1`](git-internals.html?scene=1) |
| [She has opinions](cg-montage.html) | cg answering eleven commands, getting worse | [`?set=2`](cg-montage.html?set=2) (feelings) |
| [The tier ladder](curse-tiers.html) | From Tier 0 Safe to Tier 4 Catastrophic | [`?tier=3`](curse-tiers.html?tier=3) |
| [Her tier, worked out](her-tier.html) | Where she started, temper, your toxicity, the cap | [`?chapter=2`](her-tier.html?chapter=2) |
| [Code decay](code-decay.html) | A file rots over 30 days, and a commit brings it back | |
| [Boss fight](boss-fight.html) | A pull, a merge conflict, a timed fight | |
| [The breakup](breakup.html) | The closure check and all three endings | [`?ending=a`](breakup.html?ending=a), [`b`](breakup.html?ending=b), [`c`](breakup.html?ending=c) |
| [Anti-cheat](anti-cheat.html) | Plain git behind her back, XP farming, editing her diary | [`?scene=2`](anti-cheat.html?scene=2) |

All of them are 16:9. To record them as MP4 files, see the
[README in `cursed-git-video/`](https://github.com/spiritpaper/cursed-git/tree/main/cursed-git-video).
