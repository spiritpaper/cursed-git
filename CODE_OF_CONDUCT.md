# Code of conduct

Cursed GIT is a game about a toxic relationship. The people making it aren't one.

- **Be kind.** Disagree about code, never about people. Assume good intent.
- **Be welcoming.** Beginners are this project's whole audience; questions are always fine.
- **No harassment**, in issues, pull requests, discussions or anywhere this project lives:
  no insults, no personal attacks, no unwanted sexual attention, no doxxing, no discrimination.
- **Her lines are fiction.** Writing a manipulative character is fine; using her voice on a
  real person is not.

If someone makes you feel unwelcome, open an issue (or, if it's sensitive, contact the
maintainer, [@spiritpaper](https://github.com/spiritpaper), privately). The maintainer may edit
or remove contributions, and block people who don't follow this.

This follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
